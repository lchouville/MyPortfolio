# Portfolio

Portfolio personnel de Luka Chouville (projets, expérience, formation).

Les règles sont dans `.claude/rules/` (chargées automatiquement) :
- `workflow.md` : langue du code, début de projet, skills, tâches longues, seuils d'usage, économie de tokens
- `git.md` : Gitflow, branches, commits, PR, versionnage, `visual-ref/`
- `design.md` : étapes de conception (cahier des charges, données, user flows, maquettes, prototype, technique)
- `quality.md` : priorités qualité, TDD, secrets `.env`, RGAA/RGPD, mobile first
- `docs.md` : README minimal, site détaillé FR/EN, notes de version, `portfolio.json`
- `cicd.md` : Actions, sécurisation, release, build compilé, gh-pages
- `project.md` : stack, architecture, conventions (spécifique à ce projet, à remplir)
